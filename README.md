# 📊 Sales & Business Performance Dashboard

An end-to-end Data Analytics project that analyzes sales data to uncover business insights using **Power BI, SQL, and Python (Pandas)**. The project demonstrates the complete analytics workflow, from data cleaning and transformation to visualization and business reporting.

---

## 🚀 Project Overview

The goal of this project is to transform raw sales data into meaningful insights that help businesses make informed decisions. The dataset was cleaned, analyzed, and visualized to identify trends in sales, profit, customer behavior, and regional performance.

---

## 🛠️ Tech Stack

- Power BI
- SQL
- Python
- Pandas
- Microsoft Excel

---

## 📂 Project Workflow

1. Collected and explored the sales dataset.
2. Cleaned and transformed the data using Python (Pandas).
3. Performed Exploratory Data Analysis (EDA).
4. Queried the dataset using SQL to generate business insights.
5. Built an interactive Power BI dashboard.
6. Presented key performance indicators (KPIs) and business trends.

---

## 📈 Dashboard Features

- 📌 KPI Cards (Sales, Profit, Orders)
- 📊 Sales Trend Analysis
- 🌍 Regional Performance Analysis
- 🛍️ Category & Sub-category Analysis
- 👥 Customer Insights
- 🎯 Interactive Filters & Slicers
- 🔍 Drill-through Reports

---

## 📊 Business Insights

- Identified top-performing products and categories.
- Analyzed monthly sales and profit trends.
- Compared regional sales performance.
- Evaluated customer purchasing behavior.
- Generated insights to support data-driven business decisions.
